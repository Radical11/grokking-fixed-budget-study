# Course reference documents

The project used the supplied BAMAT207 Probability and Statistics theory/laboratory syllabus. Its two PDF reference documents remain in the private coursework archive rather than being redistributed here. Their original SHA-256 metadata is in `source_hashes.json`; the public concept mapping is `../docs/SYLLABUS_MAP.md`.

All experimental inputs, labels, partitions and training records are available publicly in the code and `data/`. No unavailable course PDF is needed to reconstruct the scientific results with the public verifier.
